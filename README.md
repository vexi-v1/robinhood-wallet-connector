# Robinhood Wallet connector

A community-maintained Robinhood Wallet connector by Vexi. This project is not affiliated with or endorsed by Robinhood.

Implementation is tracked by Vexi specification ticket **TK-465**. The repository is being prepared for an EIP-1193 provider, a dedicated connection interface, and wagmi, RainbowKit, and Web3-Onboard integrations.

Wallet compatibility, device pairing, package publication, and production deployment are separate verification stages. Repository availability does not certify any of them.

## Development

Follow `AGENTS.md`. Product changes require an accepted Vexi specification and a claimed ticket before implementation.
